# EPP XML schemas

These schema files are unmodified copies from the
[IANA XML registry](https://www.iana.org/assignments/xml-registry/xml-registry.xhtml#schema).
They are published in RFC 5730 (epp, eppcom), RFC 5731 (domain), RFC 5732 (host),
RFC 5733 (contact), RFC 3915 (rgp), RFC 5910 (secDNS) and RFC 8807 (loginSec) and are
used here only to validate the commands the module builds.
